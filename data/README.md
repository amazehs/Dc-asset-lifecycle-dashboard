# data

Synthetic, fictional source data produced by `scripts/generate_data.py` (seed 42, so every run is identical).

| File | Contents |
|---|---|
| asset_register.csv | 200 serialized assets across 4 fictional sites |
| spare_stock.csv | 14 bulk spare-part types x 4 sites |
| rma_cases.csv | 36 RMA cases linked to Asset IDs |
| procurement.csv | 55 FY2026 purchase requests |
| asset_audits.csv | 55 physical audit records |
| budget_inputs.csv | Approved budgets and other planned spend by site and category |
| meta.json | Reference date, seed and the IDs used in the worked examples |

Prices are illustrative planning figures, not market quotations.
