# Regional Data Centre IT Asset Management and Financial Dashboard: Simulated Case Study

A portfolio project in Microsoft Excel showing how a regional asset manager could track data centre hardware from purchase to retirement, keep spare parts available, run RMA (return merchandise authorization) cases, audit physical inventory, and control the hardware budget.

> **Simulated data.** All sites, assets, serial numbers, suppliers, prices and events are fictional and were generated by a seeded Python script. Prices are illustrative planning figures, not market quotations. The project was not developed for, and contains no information from, any real company.

**Author:** Syed Hamza Shah, MSc Electronics and Communications Engineering

## What it demonstrates

| Skill area | Where to look |
|---|---|
| IT asset inventory and lifecycle tracking (200 serialized assets, 4 sites) | `Asset_Register` sheet |
| Warranty expiry, data-quality and inspection flags | `Asset_Register`, columns P to Z |
| Spare-parts reorder point, inventory position and replenishment quantity | `Spare_Stock` |
| RMA workflow, ageing and SLA tracking, including a GPU spare-swap example | `RMA_Tracker`, README sheet |
| Procurement stages, commitments vs actuals, with no double counting | `Procurement` |
| Budget, year-end forecast, variance, monthly reporting, CAPEX/OPEX | `Budget_Forecast` |
| Physical audit accuracy and corrective actions | `Asset_Audits` |
| Executive KPIs, risk watchlist, native charts | `Management_Dashboard` |
| PivotTables (build steps plus formula cross-checks) | `Pivot_Analysis` |
| Field, KPI and status definitions | `Data_Dictionary` |

Excel features used: structured Tables, named ranges, COUNTIFS, SUMIFS, INDEX/MATCH (with the XLOOKUP equivalent explained), IF/AND/OR, IFERROR, SUMPRODUCT, EOMONTH, date arithmetic, data-validation drop-downs, formula-based conditional formatting, currency and percentage formats, and native bar/column charts. No macros, VBA or external connections are used.

## Using the workbook

1. Download `output/DC_Asset_Lifecycle_Financial_Dashboard.xlsx` and open it in Microsoft Excel (365, 2021 or 2019). Click **Enable Editing** if it opens in Protected View, so formulas calculate.
2. Start on the **README** sheet. The yellow cells are settings (reporting date 12 Nov 2026, RMA target 30 days, warranty window 90 days, and so on); every formula reads them by name.
3. Open **Management_Dashboard** for the summary, then follow any number back to its source sheet.
4. Build the three PivotTables using the steps on the **Pivot_Analysis** sheet (about 5 minutes).

## Key calculations

| Metric | Formula |
|---|---|
| Reorder point | Avg monthly consumption x lead time (months) + safety stock |
| Inventory position | On hand + on order - reserved |
| Suggested order | If position <= reorder point: MAX(0, ROUNDUP(target - position)) |
| Forecast year-end | Actual + outstanding commitments + additional expected |
| Budget variance | Approved budget - forecast (positive = underspend) |
| Audit accuracy | Matching audit records / all audit records (sample only) |
| Operational utilisation | Deployed assets / active (non-retired) assets |

Budget treatment: invoiced = actual; PO issued or received but not invoiced = commitment; not yet ordered = pipeline; cancelled = excluded. Every request falls in exactly one bucket.

## Rebuilding from source (optional)

Requires Python 3.10+.

```bash
pip install -r requirements.txt
python scripts/generate_data.py      # writes data/*.csv
python scripts/build_workbook.py     # writes output/DC_Asset_Lifecycle_Financial_Dashboard.xlsx
```

To validate: open the rebuilt workbook in Excel, save it (so calculated values are stored), then run

```bash
python scripts/validate_workbook.py output/DC_Asset_Lifecycle_Financial_Dashboard.xlsx
```

## Simulated findings (summary)

At the 12 Nov 2026 reporting date: 129 of 191 active assets are deployed (67.5%; 87.5% for servers and switches). 16 RMA cases are open, 6 of them past the 30-day target. 10 spare-part lines are at or below reorder point, 3 of them critical. The audit sample shows 83.6% accuracy with 5 unresolved discrepancies, including a spare GPU module that could not be located. The region is forecast €0.69M under its €8.13M budget, but three lines are at overrun risk. Details and recommendations are in [docs/Management_Report.md](docs/Management_Report.md).

## Limitations

The data are synthetic and deliberately include a few exceptions (duplicate serial, missing fields, late POs) for the analysis to find. Native PivotTables must be built in Excel because the Python library cannot create them. The model simplifies accounting (straight-line budget phasing; all commitments assumed invoiced within the financial year) and is a demonstration, not a production asset-management system.
